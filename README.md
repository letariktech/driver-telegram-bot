   ቡድን መሪ ተጨማሪ ቡድኑን ያያል፣ ካምፔንም ይፈጥራል። ማጽደቅ እና ክፍያ ግን አይችልም።

### ካምፔኖች
- ዳሽቦርድ → **📣 ካምፔኖች**፦ ስም፣ ቦታ፣ ቀን፣ ኮሚሽን እና የሚሳተፉ ሴልሶች።
- **🖨 QR** ለእያንዳንዱ ሴልስ የሚታተም QR ያወጣል።
- ኮሚሽን የሚቆጠረው አሽከርካሪው **ለስራ ዝግጁ ሲሆን** ነው። መጠኑ የካምፔኑ ነው፤ ካምፔኑ ካልገለጸው የቅንብሮቹ መነሻ ኮሚሽን ይወሰዳል።
- በሴልስ የመጣ አሽከርካሪ የጥቆማ ሽልማት አያስከፍልም።
- ክፍያ፦ **ሴልሶች → የኮሚሽን ክፍያ → "ተከፍሏል"**።

### Telegram የሌለው አሽከርካሪ
- ሴልሱ በገጹ **➕ መዝግብ** ብሎ ቅጹን ይሞላል።
- ሰነዶቹን ቦቱ በሴልሱ ቻት አንድ በአንድ ይጠይቃል።
- ውሳኔዎችና ቀጠሮዎች ለአሽከርካሪው **በSMS**፣ ቅጂው ደግሞ ለሴልሱ ይደርሳሉ።
- አሽከርካሪው በኋላ Telegram ሲከፍት "በሴልስ ተመዝግቤያለሁ"ን ይጫናል። ቁጥሩን ሲያጋራ ወይም በSMS የሚመጣውን ኮድ ሲያስገባ መዝገቡ ይገናኛል።

### SMS (AfroMessage)
1. በAfroMessage አካውንት ይክፈቱ እና የላኪ ስም (Sender ID) ያስጸድቁ።
2. ዳሽቦርድ → **⚙️ ቅንብሮች → SMS**፦ API token፣ Sender name፣ (ካለ) Identifier ID ያስገቡ፣ **SMS ይላክ**ን ያብሩ፣ ከዚያ "የሙከራ SMS ላክ"።
3. የወር ገደብ (መነሻ 2000) ሲደርስ መላክ ይቆማል፣ ለአስተዳዳሪው ማሳወቂያ ይመጣል።
4. የትኞቹ SMSዎች እንደሚላኩ በዓይነት ማብራት/ማጥፋት ይቻላል።
5. የነገ ቀጠሮ ማስታወሻ በየቀኑ ጠዋት (cron) ለሁሉም ይላካል።
