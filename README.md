## ለአሽከርካሪው

**ቅጽ (5 ደረጃ)፦**
1. **የግል መረጃ፦** ሙሉ ስም፣ ስልክ፣ Telebirr፣ የትውልድ ቀን (21+)፣ ክፍለ ከተማ፣ ቋንቋዎች፣ የአደጋ ጊዜ ተጠሪ
2. **መንጃ ፈቃድ እና ልምድ፦** ቁጥር፣ ደረጃ፣ ማብቂያ ቀን፣ የልምድ ዓመታት፣ ቀድሞ የሰራበት ride-hailing
3. **መኪና፦** የራሱ / የሌላ ሰው / የለውም፤ ሞዴል፣ ዓመት፣ ቀለም፣ መቀመጫ፣ AC፣ ሰሌዳ፣ (የባለቤቱ መረጃ)
4. **አገልግሎት፦** Cabby Share / Cabby Reserve፣ የስራ ሰዓት፣ የስልክ ዓይነት፣ የጠቋሚ ኮድ
5. **ማረጋገጫ እና ስምምነት**

**ሰነዶች (አንድ በአንድ በቻት)፦** መንጃ ፈቃድ፣ መታወቂያ፣ የራስ ፎቶ — መኪና ካለው ደግሞ ሊብሬ፣ መድን፣ ቦሎ፣ የመኪና ፊት (ከሰሌዳው ጋር)፣ የመኪና ውስጥ — የሌላ ሰው መኪና ከሆነ የባለቤቱ ውክልና።

**ሌሎች፦**
- `/status` — የሂደቱን ደረጃ በምልክት ያሳያል

## ማዋቀር

### 1. ኮዱን ይጫኑ
ፋይሎቹን በrepo ውስጥ ይተኩ እና ወደ `main` commit ያድርጉ — Cloudflare በራሱ deploy ያደርጋል። ያለው ዳታቤዝ እና የተመዘገቡ አሽከርካሪዎች **ይቆያሉ**፤ አዳዲስ አምዶች በራሳቸው ይጨመራሉ (የቀድሞ "approved" → "active")።

### 2. ሚስጥሮች (Settings → Variables and Secrets)

| ስም | ምንድን ነው |
|---|---|
| `BOT_TOKEN` | ከ @BotFather |
| `WEBHOOK_SECRET` | ረጅም የዘፈቀደ ጽሑፍ (ፊደል፣ ቁጥር፣ `_` `-`) |
| `ADMIN_CHAT_ID` | ማመልከቻዎች የሚደርሱበት ቻት/ግሩፕ (`-100…`) |
| `ADMIN_IDS` | ማጽደቅ የሚችሉ ሰዎች Telegram ID በኮማ፦ `111,222` |

`wrangler.toml` → `[vars]`፦ `SUPPORT_CONTACT`፣ `DRIVER_APP_LINK` (የDriver መተግበሪያ ማውረጃ)፣ `DRIVER_GROUP_LINK` (የአሽከርካሪዎች ግሩፕ) — ሲጸድቁ ለአሽከርካሪው ይላካሉ።

### 3. ቦቱን ያገናኙ
```
https://driver-telegram-bot.letarik.workers.dev/setup?key=WEBHOOK_SECRET
```
`"ok": true` እና `"admin_chat": "ok (…)"` ማየት አለብዎት። `FAILED` ከሆነ ከጎኑ ምክንያቱ ይጻፋል።
